# Support

Spice is pre-1.0. Use the owning repository's discussions or issue tracker for
reproducible bugs and focused framework questions. Use
`spice-framework/development` for compatibility, workspace, and coordinated
release problems.

Before filing an issue, include the Spice artifact versions, Go 1.26.5 output,
operating system and architecture, a minimal valid-Go reproduction, generated
freshness status, and the exact command and diagnostic output. Do not include
credentials or security-sensitive details in public issues; follow
`SECURITY.md` instead.
